# MEPHI Session Project 2026: Безопасность GNU/Linux (РЕД ОС 8)

Учебный проект по курсу «Безопасность GNU/Linux»: настройка базовых средств защиты ОС, развёртывание веб‑сервера и публикация результатов в соответствии с требованиями задания.

## Цель проекта

Реализовать типовой сценарий настройки безопасности для ГИС на сертифицированном дистрибутиве РЕД ОС 8 (сертификат ФСТЭК №4060):
* настроить сеть, пользователей и политики паролей;
* развернуть и настроить веб‑сервер Nginx для публикации результатов;
* реализовать дискреционное (DAC) и мандатное (MAC/SELinux) управление доступом;
* подготовить артефакты и опубликовать результаты на GitHub.

---

## Выполненные разделы задания

| Раздел | Содержание | Подтверждающие файлы |
|--------|------------|----------------------|
| 1. Установка и сеть | Настройка DHCP, имени хоста `mephi-2026.domain.local`, проверка связности | `ping.out` |
| 2. Управление ПО | Обновление системы, установка Nginx, libcap-ng-utils, rpm‑пакет tcpdump | `dnf.out` |
| 3. Файловые системы | Создание раздела на `/dev/sdb`, ext4 с меткой `MEPHI_WEB`, автомонтирование через метку в `/etc/fstab` | `fstab`, `stat.out` |
| 4. Сервисы | Запуск Nginx, автозапуск, сбор логов сервиса | `journalctl.out` |
| 5. Управление доступом | Пользователи `user1–3` (UID 5501–5503), кураторы `curator1–2` в группе `curators` (GID 4444), настройка прав на `/data/mephi-2026`, настройка capabilities для `tcpdump` | `passwd`, `group`, `getcap.out`, `stat.out` |
| 6. Аутентификация | Ограничение локального входа для кураторов, политика паролей: длина ≥12, смена каждые 90 дней | `pwquality.conf`, `shadow` |
| 7. Тестирование | Веб‑страница в `/mephi-web/index.html`, проверка через `curl` | `index.html`, `curl.out` |
| 8. Публикация | Подготовка артефактов, загрузка в GitHub, публичный доступ | Все файлы в репозитории |

## Артефакты и их назначение

В репозиторий загружены файлы, требуемые заданием (раздел 8.3), для проверки выполнения критериев оценивания:

* `mephi-screenshot.png` — визуальное подтверждение корректной работы веб‑страницы (текст `Hello from Student: <ВАШ_НОМЕР>`).
* `history.out` — история выполненных команд, демонстрирующая последовательность действий.
* `ping.out`, `dnf.out`, `journalctl.out`, `curl.out` — результаты проверок по соответствующим разделам.
* `stat.out` — информация о правах и контекстах SELinux для ключевых директорий.
* `getcap.out` — подтверждение настройки привилегий для `tcpdump`.
* `getenforce.out` — текущий режим SELinux (`Enforcing`).
* Системные файлы из `/etc`: `passwd`, `shadow`, `group`, `fstab`, `pwquality.conf` — подтверждают настройку пользователей, групп, монтирования и парольной политики.

> **Примечание по файлу `shadow`:**  
> Файл `/etc/shadow` включён в репозиторий в соответствии с требованием задания (таблица в разделе 8.3) для демонстрации настроенных политик паролей и хешей. Поскольку это учебный репозиторий для сдачи проекта, файл оставлен в составе артефактов.
